# Comparaison avec la version Amiga

La conversion Amiga d'OutRun (1989) n'a **pas été mesurée** dans ce travail : ni cadence, ni résolution affichée
en jeu, ni nombre de couleurs à l'écran n'ont été relevés sur une vraie machine ou un émulateur.

| | OutRun Amiga | Cannonball Falcon CT60 |
|---|---|---|
| Moteur | réécriture pour Amiga | moteur arcade recréé (Cannonball), mêmes données que la borne |
| Images/s | non mesuré | [H] 15-20 ; CT60 30 visé [HYPOTHÈSE] |
| Résolution | non mesuré | 320×224 |
| Couleurs | non mesuré | 65 536 |
| Musique | non mesuré | FM arcade (YM2151 sur DSP) ou .mod au choix |

Une mesure sous émulateur Amiga serait possible ; elle n'a pas été demandée et n'est pas faite.
